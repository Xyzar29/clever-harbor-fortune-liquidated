A make.fun entry for [Fortune Cookie for the Liquidated Trader](https://make.fun/c/u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c).

`main.ts` writes a single fortune cookie line — at most 20 words of plain
text — for a crypto trader who has just been liquidated, to
`/output/entry.txt`. The line keeps the fortune-cookie voice, states the
loss plainly, and lands the joke on the loss with a double meaning in the
last words ("long on laughter").

> Your position is gone, trader — but the cookie crumbles kindly: your next fortune comes long on laughter.

Run it with Node 22.18+:

```sh
node main.ts
```

It writes the fortune to `/output/entry.txt` (105 characters, 18 words).
